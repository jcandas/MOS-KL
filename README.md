# Reproducing the results

This package reproduces the paper's results with **three commands**. All commands
are run from the `source/` folder in the MATLAB command window, after a one-time
path setup.

## Requirements
- MATLAB (R2023b or newer) with the Statistics and Machine Learning Toolbox and
  the Deep Learning Toolbox. The Parallel Computing Toolbox is optional (the code
  falls back to serial if it is absent).
- The bundled `toolboxes/` folder (added automatically by `paths`).

---

## Step 1 — Download the data
See the **Download data** section at the bottom of this file. GCM ships with the
package (`data/Tan_data-2/GCM.txt`); ADNI and CSF are generated by you from the
raw downloads via `PrepADNI.m` / `PrepCSF.m`; newAD is private and is skipped
automatically if its data is absent.

## Step 2 — Set up paths
From the `source/` folder, type:

```matlab
paths
```

This adds every submission subfolder to the MATLAB path and records the source
root. **Run every subsequent command from the `source/` folder.**

## Step 3 — Reproduce the results (three commands)

Run them **in order** — command 2 reads the accuracy CSVs produced by command 1.

### 1. Accuracy tables
```matlab
reproduce_accuracy
```
Runs the full leave-10-pairs-out pipeline for every dataset whose data is present
(ADNI radial SVM k1=5; CSF and newAD linear SVM k1=8; GCM linear SVM k1=39) and
writes, for each, `results/acc_<dataset>.csv` with columns
`Dataset, Model, WithMLS, Level, Accuracy, Sensitivity, Specificity, AUC`.
May use the Parallel Computing Toolbox. (GCM is summarized here too because
command 2 needs its per-classifier best levels.)

> Note: the SVM results are deterministic and reproduce exactly; the neural-network
> (MLP/ResNet) columns are subject to training stochasticity (parallel execution and
> multithreaded floating-point reductions), so they may vary by a small margin
> between runs.

### 2. Runtime comparison
```matlab
reproduce_runtime
```
**Run this by itself, on an otherwise idle machine.** It measures fit+predict time
**single-core and serially** (`maxNumCompThreads(1)`, no `parfor`) over 30
leave-pair-out folds, so the comparison is fair. For each dataset it writes
`results/model_runtime_<dataset>.csv` and a bar figure
`results/figures/<dataset>_runtime.{pdf,png}`. Absolute times depend on your
hardware; the *ranking* of methods is what reproduces.

### 3. Semisynthetic experiment
```matlab
reproduce_semisyn
```
Generates KL data from GCM under the sin(15/18/20 x) deformations, Tumor training
sizes 150–50,000, evaluates radial-SVM and (linear-SVM + MLP + ResNet + baselines)
sweeps, and writes `results/acc_semisyn_v2.csv`, `results/acc_semisyn_v2_radial.csv`
(columns include `Precision`) and the scaling figures
`results/figures/semisyn_v2_sin{15,18,20}_scaling.{pdf,png}`.

> **Resource warning.** This runs at full scale and serially. The 50,000-sample
> generation peaks near **~180 GB of memory**, and the whole command takes on the
> order of **a day** on a large-memory node. It is not intended for a laptop.

All outputs land in `source/results/` (CSVs) and `source/results/figures/` (plots).

## Download data

### ADNI (blood plasma)

**Step 1. Get access to confidential ADNI data**
- Visit https://ida.loni.usc.edu/login.jsp?project=ADNI.
- Complete the data use agreement and submit your application.
- Once approved you receive login credentials for the ADNI Image & Data Archive (IDA).

**Step 2. Download plasma data**
- In the "Search & Download" dropdown, select "Study Files".
- In the left sidebar choose "Biospecimen" → "Biospecimen Results".
- Download "Biomarkers Consortium Plasma Proteomics Project RBM Multiplex Data and
  Primer (Zip file)".
- Extract `adni_plasma_qc_multiplex_11Nov2010.csv` into `source/data/`.

**Step 3. Download phenotype data**
- In "Search & Download" find "ADNIMERGE - Packages for R" and download
  `ADNIMERGE_0.0.1.tar.gz`.
- In R:
  ```r
  install.packages("Hmisc")
  install.packages("/your/path/to/ADNIMERGE_0.0.1.tar.gz", repos = NULL, type = "source")
  library(ADNIMERGE)
  data("adnimerge")
  m12 <- subset(adnimerge, VISCODE=='m12')
  bl  <- subset(adnimerge, VISCODE=='bl')
  write.csv(m12, "source/data/adni_phenotype_m12.csv", quote = F, row.names = F)
  write.csv(bl,  "source/data/adni_phenotype_bl.csv",  quote = F, row.names = F)
  ```

**Step 4. Generate the data**
- With `adni_plasma_qc_multiplex_11Nov2010.csv` and `adni_phenotype_m12.csv` in
  `source/data/`, run `PrepADNI`. The three binary datasets are written to
  `source/data/ADNI_data/`. (If your files live elsewhere, edit the two `readtable`
  paths at the top of `PrepADNI.m`.)

### CSF

Steps 1–2 are the same as for ADNI.

**Step 3. Download CSF data**
- With study set to ADNI, in "Search & Download" → "Study Files", sidebar
  "Biospecimen" → "Biospecimen Results", download
  "CruchagaLab CSF SOMAscan7k Protein matrix postQC".
- Save `CruchagaLab_CSF_SOMAscan7k_Protein_matrix_postQC_20230620.csv` into `source/data/`.

**Step 4. Generate the data**
- With `CruchagaLab_CSF_SOMAscan7k_Protein_matrix_postQC_20230620.csv` and
  `adni_phenotype_bl.csv` in `source/data/`, run `PrepCSF`. The six pairwise CSF
  datasets are written to `source/data/CSF_data/`. (If your files live elsewhere,
  edit the two `readtable` paths at the top of `PrepCSF.m`.)

### GCM
Already included at `data/Tan_data-2/GCM.txt`; nothing to download.

### newAD
Private; not included. `reproduce_accuracy` and `reproduce_runtime` skip it
automatically. If you have `newAD.txt`, place it at `source/data/newAD/newAD.txt`
and it will be included.
